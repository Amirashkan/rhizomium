# 🌱 Rhizomium Documentation

**Visual Synthesis, Rhizome-Style**

Rhizomium is a **modular GPU-based visual synthesis environment** built on WebGPU and WGSL. It allows artists, designers, and coders to **compose dynamic shaders through visual nodes**, combining mathematical, procedural, and organic structures in real time.

---

## ⚡ What is Rhizomium?

Rhizomium is a node-based shader editor that enables you to create complex, real-time visual effects by connecting simple building blocks. Think of it as:

- 🎨 **A visual programming environment** for GPU shaders
- 🧩 **A modular synthesis system** for graphics
- 🎭 **A performance tool** for live visuals and VJ work
- 🌊 **A creative playground** for generative art

### Key Features

- **WebGPU-Powered** - Hardware-accelerated rendering using modern GPU APIs
- **Visual Node Editor** - Build complex shaders by connecting nodes
- **Real-Time Performance** - Instant feedback and live editing
- **Audio Reactivity** - Sync visuals with audio input
- **External Viewer** - Multi-display output for performances
- **Save/Load System** - Manage your visual projects
- **Export Options** - Share and deploy your creations

Rhizomium embraces the **rhizome** metaphor - a non-hierarchical, interconnected network where any point can connect to any other. Your visual compositions grow organically, branching and connecting in unexpected ways.
