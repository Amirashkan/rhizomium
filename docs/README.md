# Rhizomium Documentation

**Visual Synthesis, Rhizome-Style**

Welcome to Rhizomium - a node-based visual synthesis environment for Windows. Create stunning real-time generative visuals by connecting nodes together, no coding required.

---

## What is Rhizomium?

Rhizomium is a **GPU-powered visual programming tool** where you create shaders by connecting simple building blocks called nodes. Think of it as:

- **A visual programming environment** - No code needed
- **A modular synthesis system** - Connect nodes like patching a synthesizer
- **A performance tool** - Perfect for live visuals and VJ work
- **A creative playground** - Explore generative art and procedural graphics

### Perfect For

- **VJs and Live Performers** - Real-time visuals with audio reactivity
- **Digital Artists** - Create unique generative artworks
- **Shader Enthusiasts** - Visual shader programming
- **Creative Coders** - Node-based GPU programming
- **Beginners** - Learn shader concepts visually

## What Can You Create?

### Patterns & Shapes
Combine geometric primitives, distance fields, and procedural patterns to create infinite variations.

### Generative Art
Use noise functions, fractals, and mathematical operations to create organic, evolving visuals.

### Audio-Reactive Visuals
Connect to your microphone or system audio and make visuals that dance to the beat.

### Live Performance
Create and perform with visuals in real-time, perfect for VJ work and live shows.

## Key Features

- **WebGPU Powered** - Hardware-accelerated GPU rendering
- **Audio Reactive** - Built-in audio analysis and reactivity
- **Real-Time** - Instant visual feedback as you create
- **Node-Based** - Visual programming, no coding required
- **Save/Load** - Manage multiple projects
- **Desktop App** - A native Windows app, no account needed

## System Requirements

- **OS**: Windows 10 or later (64-bit)
- **GPU**: A graphics card with WebGPU support (most from the last 5-7 years)
- **RAM**: 4GB minimum

## Philosophy

Rhizomium embraces the **rhizome** metaphor from Deleuze and Guattari - a non-hierarchical network where any point can connect to any other. Your visual compositions grow organically, branching and connecting in unexpected ways.

There's no "right" way to create - explore, experiment, and evolve.

**Compose. Evolve. Perform.**
