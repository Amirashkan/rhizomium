# Geometry Mapping System

## Overview

The GLSL Node Editor now supports mapping node outputs onto geometry (meshes) with proper UV mapping and texture coordinate propagation. This provides a foundation for future features like audio visualization, animation, and dynamic inputs.

## Architecture

### Core Components

#### 1. **MeshRenderer** (`src/scene/renderers/MeshRenderer.js`)

The base mesh renderer has been enhanced to support UV coordinates:

- **UV Buffer Support**: Vertex buffer at location 3 for UV coordinates
- **Shader Pipeline**: Passes UVs from vertex shader to fragment shader
- **Vertex Attributes**: Supports positions, normals, colors, UVs, and world positions

```javascript
// Example mesh geometry structure
const geometry = {
    positions: Float32Array,  // [x, y, z, x, y, z, ...]
    normals: Float32Array,    // [nx, ny, nz, nx, ny, nz, ...]
    colors: Float32Array,     // [r, g, b, a, r, g, b, a, ...]
    uvs: Float32Array,        // [u, v, u, v, ...] ← NEW
    indices: Uint32Array,     // [i0, i1, i2, ...]
    vertexCount: number,
    indexCount: number
};
```

#### 2. **TexturedMeshRenderer** (`src/scene/renderers/TexturedMeshRenderer.js`)

A specialized renderer for applying textures from node graph outputs to meshes:

- **Texture Binding**: Binds GPU textures generated by node graphs
- **UV-based Sampling**: Samples textures using mesh UV coordinates
- **Lighting Integration**: Combines texture colors with lighting calculations

**Usage:**

```javascript
import { TexturedMeshRenderer } from './src/scene/renderers/TexturedMeshRenderer.js';

// Initialize
const renderer = new TexturedMeshRenderer(device);
await renderer.initialize('bgra8unorm');

// Set texture from node output
renderer.setTexture(nodeOutputTexture);

// Render mesh with texture
renderer.render(
    passEncoder,
    geometry,      // Must include uvs
    viewMatrix,
    projectionMatrix,
    modelMatrix,
    { textureBlend: 1.0 }
);
```

#### 3. **FieldVisualizer** (`src/scene/FieldVisualizer.js`)

Enhanced to automatically generate UV coordinates for procedural geometry:

- **Automatic UV Generation**: Creates UVs for both point clouds and meshes
- **Multiple Projection Modes**: Planar, spherical, cylindrical
- **Configurable**: Set UV mode via `setUVMode()`

**Supported UV Modes:**

- `'planar-xz'` - Project onto XZ plane (default)
- `'planar-xy'` - Project onto XY plane
- `'planar-yz'` - Project onto YZ plane
- `'spherical'` - Spherical projection from center
- `'cylindrical'` - Cylindrical projection around Y axis

**Usage:**

```javascript
const visualizer = new FieldVisualizer(device);

// Set UV mapping mode
visualizer.setUVMode('spherical');

// Generate geometry with UVs
const geometry = await visualizer.generateMesh(fieldData);
// geometry.uvs will be automatically populated
```

#### 4. **UVTransform** (`src/utils/UVTransform.js`)

A comprehensive utility library for UV coordinate transformations:

**Basic Transformations:**

```javascript
import { UVTransform } from './src/utils/UVTransform.js';

// Scale UVs
const scaled = UVTransform.scale(uvs, 2.0, 2.0);

// Rotate UVs
const rotated = UVTransform.rotate(uvs, Math.PI / 4);

// Offset UVs
const offset = UVTransform.offset(uvs, 0.5, 0.5);

// Combined transformation
const transformed = UVTransform.transform(uvs, {
    scaleU: 2.0,
    scaleV: 2.0,
    rotation: Math.PI / 4,
    offsetU: 0.5,
    offsetV: 0.5
});
```

**UV Wrapping:**

```javascript
// Clamp to [0, 1]
const clamped = UVTransform.clamp(uvs);

// Repeat/wrap
const repeated = UVTransform.repeat(uvs);

// Mirror repeat
const mirrored = UVTransform.mirrorRepeat(uvs);
```

**UV Flipping:**

```javascript
const flippedH = UVTransform.flipHorizontal(uvs);
const flippedV = UVTransform.flipVertical(uvs);
```

**Projection Generation:**

```javascript
// Planar projection from vertex positions
const uvs = UVTransform.planarProjection(positions, 'xz', bounds);

// Spherical projection
const uvs = UVTransform.sphericalProjection(positions, { x: 0, y: 0, z: 0 });

// Cylindrical projection
const uvs = UVTransform.cylindricalProjection(positions, 'y', { x: 0, y: 0, z: 0 });
```

## Shader Integration

### Vertex Shader

UVs are passed through the vertex shader pipeline:

```wgsl
struct VertexInput {
    @location(0) position: vec3<f32>,
    @location(1) normal: vec3<f32>,
    @location(2) color: vec4<f32>,
    @location(3) uv: vec2<f32>,      // UV coordinates
}

struct VertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(0) worldNormal: vec3<f32>,
    @location(1) color: vec4<f32>,
    @location(2) uv: vec2<f32>,      // UV passed to fragment
    @location(3) worldPosition: vec3<f32>,
}

@vertex
fn main(input: VertexInput) -> VertexOutput {
    var output: VertexOutput;
    // ... transform position ...
    output.uv = input.uv;  // Pass through UVs
    return output;
}
```

### Fragment Shader

UVs are used for texture sampling:

```wgsl
@group(0) @binding(1) var colorTexture: texture_2d<f32>;
@group(0) @binding(2) var colorSampler: sampler;

@fragment
fn main(input: FragmentInput) -> @location(0) vec4<f32> {
    // Sample texture using UV coordinates
    let texColor = textureSample(colorTexture, colorSampler, input.uv);

    // Apply lighting
    let normal = normalize(input.worldNormal);
    let diffuse = max(dot(normal, lightDir), 0.0);
    let lighting = ambient + diffuse * 0.7;

    return vec4<f32>(texColor.rgb * lighting, texColor.a);
}
```

## Use Cases

### 1. Procedural Textures on Generated Meshes

Generate a mesh using marching cubes and apply a procedural texture from the node graph:

```javascript
// Generate mesh from field data
const geometry = await fieldVisualizer.generateMesh(fieldData);

// Set up textured renderer
const renderer = new TexturedMeshRenderer(device);
await renderer.initialize();
renderer.setTexture(nodeGraphOutputTexture);

// Render with texture
renderer.render(passEncoder, geometry, viewMatrix, projectionMatrix, modelMatrix);
```

### 2. Custom UV Mapping

Apply custom UV transformations to existing geometry:

```javascript
// Load or generate geometry
let geometry = meshLoader.load('model.obj');

// Apply custom UV transformation
geometry.uvs = UVTransform.transform(geometry.uvs, {
    scaleU: 2.0,
    scaleV: 2.0,
    rotation: Math.PI / 6,
    offsetU: 0.25,
    offsetV: 0.25
});

// Or regenerate UVs with spherical projection
geometry.uvs = UVTransform.sphericalProjection(
    geometry.positions,
    { x: 0, y: 0, z: 0 }
);
```

### 3. Dynamic Texture Updates

Update textures in real-time from node graph:

```javascript
// In render loop
function render() {
    // Execute node graph to generate texture
    const outputTexture = nodeGraph.execute();

    // Update renderer texture
    texturedRenderer.setTexture(outputTexture);

    // Render mesh
    texturedRenderer.render(passEncoder, geometry, viewMatrix, projectionMatrix, modelMatrix);
}
```

## Future Extensions

This geometry mapping system provides the foundation for:

### 1. **Audio Visualization**

Map audio frequency data onto mesh geometry:

```javascript
// Audio data as texture
const audioTexture = createTextureFromAudioData(audioAnalyzer.getFrequencyData());

// Apply to mesh UVs
texturedRenderer.setTexture(audioTexture);
renderer.render(passEncoder, geometry, viewMatrix, projectionMatrix, modelMatrix);
```

### 2. **Animation**

Animate UV coordinates or displacement:

```javascript
// Animate UVs over time
const animatedUVs = UVTransform.offset(
    baseUVs,
    Math.sin(time) * 0.5,
    Math.cos(time) * 0.5
);

geometry.uvs = animatedUVs;
```

### 3. **Vertex Displacement**

Use texture data to displace vertices:

```javascript
// Sample texture in vertex shader
output.position += normal * textureSampleLevel(displacementMap, sampler, uv, 0.0).r;
```

### 4. **Multi-layer Texturing**

Support multiple UV channels (UV0, UV1, etc.) for complex materials:

```javascript
geometry.uvs = [
    uv0,  // Base texture
    uv1,  // Detail texture
    uv2   // Lightmap
];
```

## Best Practices

### 1. **UV Coordinate Range**

- Keep UVs in [0, 1] range for clamped textures
- Use `UVTransform.normalize()` to ensure proper range
- For tiling textures, UVs can exceed [0, 1]

### 2. **UV Generation for Procedural Geometry**

- Choose projection mode based on geometry shape:
  - **Planar**: Flat or terrain-like surfaces
  - **Spherical**: Spherical or blob-like shapes
  - **Cylindrical**: Cylindrical or column-like shapes

### 3. **Performance**

- Generate UVs once during geometry creation
- Cache transformed UVs if transformation is static
- Use GPU-based UV transformation for dynamic effects

### 4. **Texture Coordinates**

- UV origin is bottom-left (0, 0)
- U increases to the right, V increases upward
- Use `flipVertical()` if texture appears upside-down

## Example: Complete Workflow

```javascript
import { FieldVisualizer } from './src/scene/FieldVisualizer.js';
import { TexturedMeshRenderer } from './src/scene/renderers/TexturedMeshRenderer.js';
import { UVTransform } from './src/utils/UVTransform.js';

// 1. Generate procedural geometry
const visualizer = new FieldVisualizer(device);
visualizer.setUVMode('spherical');
const geometry = await visualizer.generateMesh(fieldData);

// 2. Optional: Transform UVs
geometry.uvs = UVTransform.transform(geometry.uvs, {
    scaleU: 2.0,
    scaleV: 2.0,
    rotation: Math.PI / 4
});

// 3. Set up textured renderer
const renderer = new TexturedMeshRenderer(device);
await renderer.initialize('bgra8unorm');

// 4. Execute node graph to generate texture
const nodeTexture = await nodeGraph.execute();
renderer.setTexture(nodeTexture);

// 5. Render
renderer.render(
    passEncoder,
    geometry,
    viewMatrix,
    projectionMatrix,
    modelMatrix
);
```

## Technical Details

### Vertex Buffer Layout

| Location | Attribute | Format | Stride | Description |
|----------|-----------|--------|--------|-------------|
| 0 | Position | float32x3 | 12 bytes | Vertex position (x, y, z) |
| 1 | Normal | float32x3 | 12 bytes | Vertex normal (nx, ny, nz) |
| 2 | Color | float32x4 | 16 bytes | Vertex color (r, g, b, a) |
| 3 | UV | float32x2 | 8 bytes | Texture coordinates (u, v) |

### Uniform Buffer Layout

| Offset | Size | Type | Description |
|--------|------|------|-------------|
| 0 | 64 bytes | mat4x4<f32> | Model matrix |
| 64 | 64 bytes | mat4x4<f32> | View matrix |
| 128 | 64 bytes | mat4x4<f32> | Projection matrix |
| 192 | 12 bytes | vec3<f32> | Light direction |
| 204 | 4 bytes | f32 | Texture blend factor |

### Bind Group Layout (TexturedMeshRenderer)

| Binding | Type | Stage | Description |
|---------|------|-------|-------------|
| 0 | Uniform Buffer | Vertex + Fragment | Transform matrices and params |
| 1 | Texture 2D | Fragment | Color texture from node output |
| 2 | Sampler | Fragment | Texture sampler (linear, repeat) |

## Summary

The geometry mapping system provides:

- Full UV support in mesh rendering pipeline
- Automatic UV generation for procedural geometry
- Multiple UV projection modes (planar, spherical, cylindrical)
- Comprehensive UV transformation utilities
- Textured mesh rendering with node graph integration
- Foundation for audio, animation, and dynamic inputs

This system enables rich visual effects by combining procedural geometry generation with shader-based texture mapping, all within the node-based workflow.
